# *Real Goal:**

Необходимо разработать мини приложение (сайт) для опроса клинетов нашего дома престарелых. 

То есть с родственников подопечных требуется собирать обратную связь, как их родственникам у нас проживается, все ли устаривает и так далее.

Я подготовил вводный текст, сам опрос + фотографии руководителя с подопечными.

Надо сделать несоклько акцентов

1. Что это честная оценка и она ухожит напрямую директору, управляющие пансионатов их не видят

2. Что это перснализированная оценка и она влияет только на улучшение качества рьсулживания, поэтому хочется видеть обхективную оценку

Так же добавил отдельное фото директора.

+ потом будет внутренение страницы с админкой, где мы сможем увидеть как у нас меняется картина по конкретному педопечному (опрос будет периодический) какие средние показатели по конкретному пансионату и по всей сети пансионатов

Не отвечай на мой вопрос сразу. Сначала проверь, правильный ли это вопрос. 

— Определи, какую реальную цель я пытаюсь решить. 

— Укажи предположения, которые я делаю (и которые могут быть ошибочными). 

— Покажи слепые зоны — что я не учитываю. 

— Задай 3–5 уточняющих вопросов. 

— Переформулируй мой вопрос в 2–3 более точных и полезных варианта.
